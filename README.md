# Hermes: агент-аудитор для AI-отдела

## Что это

Hermes Agent это самостоятельный AI-агент от Nous Research. Он живёт на сервере, общается с тобой
в Telegram, умеет ходить в браузер, читать файлы, запускать команды и помнить прошлые разговоры.
Claude Code ему не нужен, у него свой движок.

В этом репозитории Hermes настроен в роли **аудитора**. Его личность и правила лежат в файле
`SOUL.md`.

## Зачем аудитор

Когда агентов несколько, они сами отчитываются о своей работе: «отчёт готов», «воронка
настроена», «цифры собраны». Аудитор проверяет эти отчёты независимо:

- открывает сам результат: страницу, бота, таблицу, отчёт;
- проходит путь клиента так, как его пройдёт живой человек;
- сверяет цифры аналитика с первоисточником (кабинет, статистика соцсети);
- находит дефект и описывает его так, чтобы его можно было воспроизвести и исправить.

Сам он ничего не чинит и не публикует. Нашёл проблему, описал, передал тебе или агенту, чья это
работа. Так ошибка одного агента не уходит дальше по цепочке.

## Что понадобится

- Сервер Ubuntu 22.04 или 24.04: хватит 2 ядер и 2-3 ГБ памяти. Можно тот же, где живут
  остальные агенты.
- Новый бот в Telegram: создай в @BotFather и сохрани токен.
- Свой Telegram ID: его покажет бот @userinfobot.
- Модель: подписка ChatGPT (Plus или Pro) либо ключ OpenRouter.

## Установка

1. Зайди на сервер и выполни одну команду:

```
curl -fsSL https://raw.githubusercontent.com/izmukovvladimir-cyber/hermes-auditor/main/install.sh | bash
```

Она поставит Hermes и положит роль аудитора в `~/.hermes/SOUL.md`.

2. Открой новый терминал (или переподключись к серверу), чтобы команда `hermes` стала видна.
   Затем подключи модель и Telegram. Мастер задаст вопросы по шагам: какую модель взять, токен бота,
   твой Telegram ID (только он сможет писать агенту).

```
hermes setup
```

Если выбираешь подписку ChatGPT и вход не проходит: в ChatGPT открой Настройки, затем
«Безопасность и вход», внизу включи «авторизацию кода устройства для Codex» и повтори вход.

3. Заполни роль под себя. Открой файл и замени метки в фигурных скобках: твоё имя, каких
   агентов проверяет аудитор, какие личные данные клиентов нельзя отправлять наружу.

```
nano ~/.hermes/SOUL.md
```

4. Запусти агента фоном, чтобы он работал и после перезагрузки сервера:

```
hermes gateway install --start-now
```

Ставишь под пользователем root? Тогда так:

```
hermes gateway install --system --run-as-user root --start-now
```

5. Проверь: напиши своему боту «Кто ты и что проверяешь?». Он должен ответить как аудитор.

## Что с ним делать

Примеры задач:

- «Аналитик прислал недельный отчёт. Сверь цифры охватов с самой статистикой Instagram.»
- «Пройди воронку по слову ГАЙД как новый подписчик и скажи, где человек может застрять.»
- «Маркетолог говорит, что дожимы настроены. Проверь, что они реально приходят.»
- «Посмотри этот пост перед публикацией: факты, ссылки, обещания.»

Ответ всегда в одном формате: вывод, доказательство, риск, следующий шаг.

## Обновить роль

Повтори команду установки из шага 1. Старый `SOUL.md` сохранится рядом с пометкой `.bak` и датой.
Свои метки после этого нужно будет заполнить заново или перенести из копии.
